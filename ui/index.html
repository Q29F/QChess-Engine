About this engineEvaluation, search and draws

Classical chess

Moves follow standard chess rules, including castling, en passant and promotion. Positions and full move histories are validated by the local Python process.

Bounded material search

The engine uses deterministic alpha-beta search with material values and terminal results. It has no positional model or opening book. Search scores describe the searched line, while the position score reports the board currently shown.

Explicit draw claims

Automatic game endings stop play. Available threefold and fifty-move claims appear as concrete choices; an announced move is recorded with the claim and is not played. Games stop at 512 half-moves or the supported FEN counter limit.
